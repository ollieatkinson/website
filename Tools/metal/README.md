# Build-time Metal translator

These three MiniSwift Metal browser artifacts were moved unchanged from
`Assets/browser-runtime/metal` at website commit
`266fbca050b752e540f96dc1c4202f88d7e82b99`. They are used by
`node Tools/compile-shader.cjs`, and are no longer shipped to visitors.

The original vendoring did not record an upstream release/source revision or
separate license. These binaries are not provided by the public MSF frontend
repository; do not label them as a build of its latest HEAD. Exact retained
artifact hashes are in `artifacts.json`.

The translator supports a subset of Metal and has WGSL emission limitations.
Use intermediate values for bitwise comparisons and mixed boolean operators,
and avoid WGSL reserved identifiers. Unsigned literal initializers lose their
suffix, so unsigned accumulators start from a typed expression (`state & 0u`).
The translator also omits storage-buffer write access; `compile-shader.cjs`
restores `read_write` on the compute output buffer's exact declaration and fails
if that declaration changes. Simulation rules remain entirely in Metal. `npm test` checks generated bytes against Metal source and
compiles/renders the resulting WGSL in a real WebGPU browser.
